# Manejador de Inventarios

Aplicación web Full Stack para la gestión de inventario, desarrollada como proyecto de portafolio para practicar el desarrollo de aplicaciones modernas con frontend, backend, APIs REST y bases de datos.

## Tecnologías

Frontend: Astro, React, Tailwind CSS
Backend: C#, .NET 8, ASP.NET Core Web API
Base de datos: Microsoft SQL Server
ORM: Entity Framework Core
Herramientas: Git, GitHub, Swagger

## Funcionalidades

Crear, consultar, editar y eliminar productos.
Persistencia de datos mediante SQL Server.
API REST para la comunicación entre frontend y backend.
Interfaz responsive.

## Estado

V1 - MVP

Actualmente incluye las funcionalidades básicas de gestión de productos mediante operaciones CRUD.
